# پلنر دوره آموزشی — نسخه‌ی اندروید

همان برنامه‌ی وب شما، ولی کاملاً داخل گوشی و بدون سرور و بدون اینترنت.

## ساخت فایل APK (بدون دانستن اندروید)

### راه ۱ (پیشنهادی): ساخت خودکار روی GitHub — حدود ۱۰ دقیقه

۱. در github.com یک حساب بسازید و یک مخزن (Repository) **خالی** بسازید (می‌تواند Private باشد).

۲. در ترمینال، داخل همین پوشه:

```bash
git init
git add .
git commit -m "course planner android"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git   # آدرس مخزن خودتان
git push -u origin main
```

۳. در صفحه‌ی مخزن، تب **Actions** را باز کنید. کار «Build APK» خودش شروع می‌شود (۴ تا ۸ دقیقه).

۴. وقتی تیک سبز خورد، واردش شوید و پایین صفحه در بخش **Artifacts** فایل `CoursePlanner-APK` را دانلود کنید.
   داخل آن zip فایل `app-debug.apk` است.

### راه ۲: Android Studio

۱. Android Studio را نصب کنید، `File ▸ Open` و همین پوشه را انتخاب کنید و صبر کنید همگام‌سازی (Sync) تمام شود.
۲. `Build ▸ Build Bundle(s) / APK(s) ▸ Build APK(s)`.
۳. فایل در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## نصب روی گوشی

فایل APK را به گوشی بفرستید (تلگرام، USB، ...) و بازش کنید. اندروید یک‌بار می‌پرسد «اجازه‌ی نصب از این منبع؟»؛ اجازه بدهید.
(اندروید ۸ یا بالاتر لازم است. چون APK با کلید آزمایشی امضا شده، Play Protect ممکن است هشدار بدهد؛ برای استفاده‌ی شخصی مشکلی نیست.)

## نحوه‌ی استفاده

۱. «＋ برنامه‌ی جدید» ▸ «انتخاب پوشه…» ▸ در پنجره‌ی اندروید به پوشه‌ی دوره بروید و «استفاده از این پوشه» را بزنید.
   (اندروید اجازه نمی‌دهد خود ریشه‌ی حافظه یا پوشه‌ی Download را انتخاب کنید؛ پوشه‌ی خود دوره را انتخاب کنید.)
۲. بقیه‌ی کار مثل نسخه‌ی دسکتاپ: برنامه‌ریزی، چک‌لیست، ⏱ زمان توقف.
۳. با زدن روی هر ویدیو، پلیر داخلی باز می‌شود، زمان توقف را خودش ذخیره می‌کند و دفعه‌ی بعد از همان‌جا ادامه می‌دهد.

## تفاوت با نسخه‌ی دسکتاپ

| دسکتاپ | اندروید |
|---|---|
| سرور FastAPI + مرورگر | WebView داخل برنامه؛ همان `index.html` |
| ffprobe / pymediainfo | `MediaMetadataRetriever` خود اندروید |
| تایپ مسیر پوشه | انتخاب‌گر پوشه‌ی اندروید (SAF) |
| mpv / VLC با IPC | پلیر داخلی (Media3 ExoPlayer) یا «پلیر خارجی» |
| دانلود JSON گزارش/برنامه | حذف شد |

داده‌ها در حافظه‌ی خصوصی برنامه ذخیره می‌شوند (همان ساختار JSON نسخه‌ی دسکتاپ). با حذف برنامه از گوشی، داده‌ها هم پاک می‌شوند.

## محدودیت‌ها

- پلیر داخلی فقط کدک‌هایی را پخش می‌کند که خود گوشی دارد. بعضی فایل‌ها (AVI/WMV قدیمی، یا صدای AC3/DTS در MKV) ممکن است تصویر یا صدا نداشته باشند. در این حالت در دکمه‌ی «پلیر» گزینه‌ی «پلیر خارجی» را بزنید و با VLC یا MX Player باز کنید (زمان توقف خودکار فقط با پلیر داخلی ثبت می‌شود).
- اسکن پوشه‌های بزرگ (چند صد ویدیو) ممکن است ۱ تا ۲ دقیقه طول بکشد.

## ساختار پروژه

```
app/src/main/assets/index.html          رابط کاربری (همان صفحه‌ی قبلی، کمی تغییر یافته)
app/src/main/java/app/courseplanner/
    MainActivity.kt   WebView + پل بین صفحه و Kotlin + انتخاب پوشه
    Api.kt            معادل app.py (همه‌ی مسیرهای /api/...)
    Planner.kt        معادل برنامه‌ریزی روزانه در course_timer.py
    Scanner.kt        اسکن پوشه و خواندن مدت ویدیوها
    Store.kt          خواندن/نوشتن فایل‌های JSON
    PlayerActivity.kt پلیر داخلی با ذخیره‌ی زمان توقف
    Util.kt           زمان، مرتب‌سازی طبیعی، ...
.github/workflows/build-apk.yml         ساخت خودکار APK
```
